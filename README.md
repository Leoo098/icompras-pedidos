# ICompras Pedidos
#### Microsserviço para o gerenciamento de Pedidos no sistema de e-commerce [**ICompras**](https://github.com/Leoo098/icompras-ecommerce). 
Este microsserviço se trata do ponto central de toda a operação do sistema, fazendo a ponte entre os demais componentes por meio do Apache Kafka 
e atualizando os status dos pedidos de acordo com a esteira de processamento.

## Stack Tecnológica
- **Backend**: Java 21, Spring Boot
- **Mensageria**: Apache Kafka
- **Bancos de Dados**: PostgreSQL
- **Container**: Docker
